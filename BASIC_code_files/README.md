# BASIC_code_files/

This directory contains the original GW-BASIC source code for TRADE.BAS, preserved as reference material.

## Contents

| File | Description |
|---|---|
| TRADE.bas | Original GW-BASIC source for the Star Traders game as it ran on the Kaypro II |
| commented basic code.BAS | Annotated version of the original BASIC source, with comments added during the Python porting process |
| basic listing.docx | Formatted printout of the original BASIC listing |

## Purpose

These files exist as the authoritative reference for:

- Original game rules and mechanics
- Pricing arithmetic and integer truncation behavior (GW-BASIC integer semantics)
- Merger and dividend logic as originally implemented
- Company formation and tie-break rules

When there is ambiguity about intended behavior, the BASIC source is the ground truth.

## Do Not Modify

These files are primary source material. They should not be edited, reformatted, or restructured.

If you need to annotate or cross-reference, add notes in `docs/economic_model.md` instead.
